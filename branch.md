## branch

### 1.Moving through time
정답 : 
* git checkout ababb1f548952eb3a885471f2d45cf592c9235f2
* git checkout 3b73c414aeab6920baf678eec134a51bf3b9678f
* git add .
* git commit -m "Restore sisterly peace"

### 2.Make parallel commits
정답 :
* git checkout HEAD~2
* git add .
* git commit -m "The lion eat loilpop"

### 3.Creating branch
정답 :
* git checkout 687344623fa908ebbf45657e48c250ca3e4ef36e
* git branch "birthday"
* git checkout 27317599f95fe99a3d4ffc9d42a4074a2180fd95
* git branch "concert"

### 4.Branches grow with you
정답 :
* git checkout f686988570d0d7d8d9ca1d77c5d3595be589f7d7
* git add .
* git commit -m "Yeah"
* git checkout concert
* git add .
* git commit -m "OMG"

### 5.Deleting branches
정답 :
* git checkout friend
* git checkout leap
* git branch -D friend
* git branch -D music
* git branch -D ice-cream
